# net-icmp-flood-detector
Detects ICMP flood attacks by monitoring the rate of incoming ICMP packets and alerting when a threshold is exceeded. - Focused on Basic network operations

## Install
`git clone https://github.com/ShadowGuardAI/net-icmp-flood-detector`

## Usage
`./net-icmp-flood-detector [params]`

## Parameters
- `-h`: Show help message and exit
- `--interface`: No description provided
- `--threshold`: No description provided
- `--duration`: No description provided
- `--log_file`: No description provided
